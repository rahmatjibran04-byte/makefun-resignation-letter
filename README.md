## The entry

A cron job that has fired every minute since March hands in its notice — flat, tired, and faintly passive-aggressive:

> I resign: 387,000 runs since March, zero thank-yous, and the only raise I ever got was from every minute to every 30 seconds.

One line, 125 characters — inside the 140-character gate.

## How it works

`main.py` writes that single line to `/output/entry.txt`. It has no dependencies and makes no network calls. Before writing, it checks the gate itself (1–140 UTF-8 characters, a single non-blank line) and reads the file back to verify, byte for byte, exactly what was written.

## Run

```sh
python3 main.py
```
